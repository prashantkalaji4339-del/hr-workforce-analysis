 HR Workforce Analysis Dashboard
 Project Overview
An interactive Power BI dashboard for analyzing employee data and workforce trends.

 Key Analysis
- Cleaned and transformed employee data using Power Query for HR reporting.
- Analyzed employee count, departments, average salary, salary distribution, and attendance.
- Studied workforce patterns by age, gender, country, and experience.
- Built an interactive dashboard with KPIs, filters, and employee-level analysis.

Tools & Technologies
- Power BI
- Power Query
- Data Cleaning & Transformation
- DAX

 Dashboard
The dashboard provides interactive KPIs, filters, and employee-level analysis for HR reporting.
